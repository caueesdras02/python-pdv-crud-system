# 🧾 Sistema PDV (Ponto de Venda)

Sistema desktop de ponto de venda (PDV) desenvolvido em Python, com interface gráfica utilizando Tkinter e persistência de dados com banco SQL.

## 🎯 Objetivo
Este projeto foi desenvolvido com o intuito de praticar o desenvolvimento de aplicações completas, integrando interface gráfica, lógica de negócio e banco de dados.

## 🧩 Funcionalidades
- Cadastro de produtos
- Listagem de produtos
- Atualização de informações
- Remoção de produtos
- Integração com banco de dados
- Interface gráfica intuitiva

## 🛠️ Tecnologias utilizadas
- Python
- Tkinter
- SQLite (ou MySQL, ajuste se necessário)
